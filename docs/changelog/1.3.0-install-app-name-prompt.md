# Prompt for the application name during install

## What changed

- The `post-create-project-cmd` hook now runs `strukt app:make` without a name,
  so `composer create-project strukt/strukt` prompts for the application name
  instead of always scaffolding `Web`.
- `README.md` documents the prompt in "Getting started" and marks `app:make`'s
  name as optional in the command table.

## Why

The install hook hardcoded `Web`, so every `create-project` produced a `Web`
application. Prompting lets the user choose the name at install time.

## Documentation

- `README.md`: install instructions and the `app:make [<name>]` command-table row.

## Tests

- None in this package (the skeleton has no test suite). The prompt itself is
  covered by `strukt/framework`'s `AppMakeTest` and manual verification of the
  hook.

## Public API impact

- The install hook no longer takes a fixed application name. This requires
  `strukt/framework` with the prompting `app:make` (>= 1.5.0).
