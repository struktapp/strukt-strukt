# 1.2.0 — Move RBAC models to the application root

## What changed

The RBAC active-record models were moved out of the module and onto the
application root, matching the framework's own convention (its scaffold places
an `Entity` model at `app/src/{{app}}/`):

- `Web\AuthModule\Model\{User,Role,Permission,RoleUser,PermissionRole}` are now
  `Web\{User,Role,Permission,RoleUser,PermissionRole}` under `app/src/Web/`.
- The generated `Web\User` `Strukt\Entity` at `app/src/Web/User.php` was
  replaced by the `strukt/ar` model: `app/src/Web/User.php` is now
  `Web\User extends Strukt\Ar\Model`. The `Entity` was legacy scaffolding and is
  no longer present.
- `Web\AuthModule\Rbac` and the `Web\AuthModule\Router\{Rbac,Auth}` routers now
  import the app-root models (`Web\User`, `Web\Role`, …).
- The scaffold's `Web\AuthModule\Tests\UserTest` was rewritten: it previously
  constructed the removed `Entity`; it now asserts `Web\User` maps to the
  `users` table and declares its schema.

The `Model/` directory under the module was removed. Table names, schema, and
behaviour are unchanged — only the namespaces moved.

## Why

Models are a domain concern, not a delivery facet. The registrar only indexes
the configured facet folders (`Controller`, `Router`, `Form`, `Tests` in
`cfg/module.ini`), so a `Model/` folder inside a module is not special — the
classes were merely PSR-4 loaded. The framework's scaffold keeps its model at
the application root (`{{app}}\User`), and `strukt/ar`'s `model:generate`
likewise defaults to an app-level namespace (`App\Model`). Placing the models
at `Web\` follows that convention and keeps them reusable across modules.

## Documentation

The booted application code lives under `app/` and `lib/`, both git-ignored, so
this is recorded here rather than in a skeleton doc page. The 1.1.0 entry
remains the historical snapshot of the original layout.

## Tests

No automated tests in the skeleton (it is a Composer project). Re-verified by
hand after the move with a cookie jar against a fresh server (database deleted
to reseed): guest `GET /user/list` → `401`; `user@strukt.test` login →
`200`/profile `200`/`/user/list` `403`; `POST /logout` → `200`;
`admin@strukt.test` `/user/list` → `200`; `GET /rbac` → `200` with the seeded
counts. `php -l` is clean across `app/src/Web` and `lib`, and no references to
`Web\AuthModule\Model` remain.

## Public API impact

Skeleton only, within git-ignored generated directories. The namespace change is
internal to the booted application; no framework or package code changed.
