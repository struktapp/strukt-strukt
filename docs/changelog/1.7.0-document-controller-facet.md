# Document the scaffolded controller facet

## What changed

- `README.md` explains what the generated `Controller/User.php` is for: it is
  scaffolded but not routed, and it demonstrates the aliased-facet lookup
  (`$this->get('au.ctr.User')`, `core('au.ctr.User')`) that the registrar
  indexes as `nr.au.ctr.User`.

## Why

- The controller was the only generated facet nothing called, which made it look
  like dead code. Recording the intent — a demonstration of the controller facet
  and the alias resolution path — keeps it and points at how to use it.

## Documentation

- `README.md`: new "Controller facet" section and a tree annotation.
