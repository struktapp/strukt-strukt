# Add a Mermaid ER diagram for the database

## What changed

- Added `docs/database/schema.mmd`, a Mermaid `erDiagram` of the RBAC SQLite
  schema: `users`, `roles`, `permissions`, and the `role_user` /
  `permission_role` pivots, with primary, unique, and foreign keys.

## Why

- Render the schema straight from a single declarative file. The diagram was
  taken from the actual `database/app.db` (`sqlite_master`), so it matches the
  tables the RBAC models create.

## Documentation

- `docs/database/schema.mmd`: the ER diagram itself.

## Tests

- None (documentation-only).

## Public API impact

- None.
