# Scaffold the full cfg and templates sets

## What changed

- `app:make`/`app:reload` now write the whole `cfg/` set (`app.ini`,
  `cache.ini`, `cmd.ini`, `module.ini`, `repo.ini`) and a project-owned
  `templates/` directory, instead of only `cfg/app.ini`.
- Each `cfg/*.ini` is generated from its own `templates/cfg/*.sgf`, so a
  project's config is independent of the framework's `cfg/*.ini` fallback and
  can be shaped per app.
- Added `/templates/` to `.gitignore`, and `bin/clear` now removes `templates/`
  alongside the other generated artifacts.
- `README.md` describes the scaffolded `cfg/*.ini` and `templates/` sets.

## Why

- The framework now loads the project's `cfg/*.ini` over its own defaults and
  resolves generator templates project-first, so the skeleton installs a
  self-contained, editable project.

## Documentation

- `README.md`: project tree and the `app:make` summary.

## Tests

- None in this package (covered by the framework suite).

## Public API impact

- None. `composer create-project` produces two additional generated
  directories.
